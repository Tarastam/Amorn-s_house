# ROADMAP — Themed Home Task App

## อัปเดต 15 ต.ค. 2026 — งานดีไซน์ 4 แมพ

- เปิดใช้งาน Space Station / Coffee Cafe / Retro Arcade / Wizard Tower ครบแล้ว พร้อมชั้นลอยและทางเดินขึ้นชั้นในแมพใหม่
- เพิ่มตัวละคร Amorn และ Border Collie แบบใหม่ รวมถึงระบบแต่งตัว ชุดตามธีม สี เครื่องประดับ พรีวิวหมุนได้ และบันทึกแยกจากข้อมูลเควส
- ทดสอบการสลับแมพ ข้อมูลเควส ชุดหลังรีโหลด และหน้าจอมือถือใน `tests/themes.js`
- งาน coin / XP / calendar / minigame / PWA ด้านล่างยังเป็นแผนอนาคต ไม่ได้รวมอยู่ในงานดีไซน์ครั้งนี้
- รูปแบบภาพยังเป็น 3D stylized ที่อ้างอิงองค์ประกอบและบรรยากาศของภาพต้นแบบ

ตารางสถานะด้านล่างเก็บไว้เป็นประวัติแผนก่อนเริ่มงานครั้งนี้

อัปเดต: 14 ต.ค. 2026

## ทิศทางที่ตกลงแล้ว

- ทำ **ครบ 4 ธีม**: Space Station, Wizard Tower, Coffee Cafe, Retro Arcade โดย **เน้นทำ Space Station ก่อน**
- ทำเป็น **3D (Three.js)** ให้คล้ายภาพ preview มากที่สุด ไม่จำเป็นต้องเหมือน 100%
- ใช้โค้ด 3D ปัจจุบัน (บ้านหลายห้อง, ตัวละครเดิน, ทีวีแดชบอร์ด) เป็นฐาน แล้วแยกส่วน "หน้าตาธีม" ออกจากส่วน "logic task"
- ธีมบ้านอุ่นเดิมจะถูกแทนที่ด้วย 4 ธีมใหม่ (ตัดทิ้งตอนจบเฟส 6)
- ผู้ใช้คนเดียว, เดสก์ท็อปเป็นหลัก, ยังไม่มีเสียง

## งานถัดไปของ Space Station (ถ้าจะขัดเกลาต่อ)

- ผังโมดูลจริงที่แยกก้อนห่างกัน (ตอนนี้ยังเป็นแกนกลาง 4x2 ห้องติดกัน ตัดมุมและมีโมดูลต่อรอบนอก) ต้องย้ายพิกัดห้อง/NODES ซึ่งเป็นงานเฟส 2
- ห้องน้ำ·สมาธิและห้องออกกำลังกายยังเรียบ เพิ่มรายละเอียดได้
- ตรวจประสิทธิภาพบนมือถือจริง (จำนวน draw call หลังเพิ่มโมดูลนอก)

## ความเสี่ยงที่ต้องดูตลอด

- **ประสิทธิภาพ**: 4 ธีมที่ละเอียดสูงใน 3D หนักกว่าบ้านเดิม ต้องรวม mesh (mergeStatic) และทดสอบบนมือถือทุกเฟส
- **ความละเอียดเทียบภาพ AI**: ภาพต้นแบบละเอียดมาก 3D ที่ทำจากทรงกล่อง/ทรงกระบอกจะเป็นสไตล์ low-poly ตามจุดประสงค์ที่ยอมรับแล้วว่า "คล้าย ไม่ต้องเหมือน"
- **ตัวละคร**: ภาพต้นแบบมีเด็กผู้หญิง + สุนัขขาวดำ ส่วนโค้ดปัจจุบันเป็น Amorn (ชาย) + Border Collie ต้องตัดสินใจก่อนเฟส 3

## วิธีทำงานต่อเฟส (workflow)

1. ก่อนเริ่มเฟส: ตกลงขอบเขตและเกณฑ์ "เสร็จเมื่อ" ของเฟสนั้น
2. ทำเป็นก้อนเล็ก เรนเดอร์ดูภาพจริงทุกครั้งที่แก้หน้าตา (ตามกฎใน `TECHNICAL.md`)
3. push เข้า `main` → Pages deploy → ดูผลบน URL จริง
4. จบเฟส: อัปเดตตารางสถานะในไฟล์นี้ และ `CLAUDE.md`
